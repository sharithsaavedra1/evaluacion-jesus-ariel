# Sitio Público Estático — Manager Library

> **Ficha ADSO 3145555 · SDD Spec-Driven Development**
> Cumple la tarea T-23: Presentación pública institucional de la biblioteca.

## Características

- **Independiente de la API (T-23):** Funciona 100% de manera estática y sin dependencias de red o servidor dinámico.
- **Totalmente Responsivo:** Adaptado a dispositivos móviles, tablets y escritorios.
- **Políticas de Préstamo Institucionales:** Detalla las 4 reglas clave de la biblioteca (14 días de préstamo, máximo 3 libros por socio, devolución individual y cuidado patrimonial).
- **Exposición de Colecciones:** Clasificación en las 5 categorías centrales (Novela, Ciencia, Tecnología, Historia, Infantil).

## Visualización

Basta con abrir el archivo `index.html` en cualquier navegador web moderno o servirlo con cualquier servidor HTTP local.
